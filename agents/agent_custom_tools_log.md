## Day 29 自定义工具开发

- **工具1**：`get_weather(city)` — 模拟天气查询
- **工具2**：`check_inventory(product_name)` — 模拟库存查询
- **工具3**：`get_user_info(user_id)` — 模拟用户信息查询
- **测试结果**：单工具调用全部正确；多工具调用（天气+库存、天气+用户信息）Agent 能依次调用两个工具并综合回答
- **关键理解**：工具名称和 docstring 是 Agent 决策的主要依据；参数命名需有意义

- **执行步骤**：4 步（天气 → 用户信息 → 库存 → 最终回答）
