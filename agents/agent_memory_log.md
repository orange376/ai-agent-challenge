## Day 32 Agent 对话记忆

- **实现方式**：将 `messages` 列表提升为全局变量 `conversation_history`，跨轮次保留历史
- **测试场景**：三轮对话——订酒店 → 要求降价 → 追问城市天气
- **测试结果**：
  - 第二轮 Agent 正确理解了“换成便宜的”指酒店预算
  - 第三轮 Agent 正确识别“那个城市”指北京
- **关键理解**：
  - `BufferMemory` 适合短对话，信息完整
  - `SummaryMemory` 适合长对话，节省 Token
  - 当前实现本质上是 `BufferMemory`
