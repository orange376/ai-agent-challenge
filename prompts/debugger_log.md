## Prompt 模板测试记录 V1（debugger.py）
 
**Prompt 版本**：V1（初始版本，CoT 思维链三步推理：错误分类、根因定位、解决方案）  
**模型**：DeepSeek v4-flash 

| 编号 | 错误类型 | 分类准确 | 根因定位准确 | 解决方案有效 | 评估 |
|------|----------|----------|-------------|-------------|------|
| 1 | SyntaxError（赋值与比较混淆） | ✅ | ✅ | ✅ | 明确指出 `=` 与 `==` 的区别，给出正确修复 |
| 2 | IndentationError（函数体缺少缩进） | ✅ | ✅ | ✅ | 准确指出第2行缺少缩进导致，修复示例正确 |
| 3 | TypeError（int + str） | ✅ | ✅ | ✅ | 提供两种方案，涵盖调用侧和函数内侧的鲁棒性处理 |
| 4 | TypeError（迭代 None） | ✅ | ✅ | ✅ | 定位到 `get_data` 返回 None，提供防御性编程建议 |
| 5 | KeyError（字典键名拼写错误） | ✅ | ✅ | ✅ | 给出三种方案（直接修正、动态添加、安全访问） |
| 6 | IndexError（列表索引越界） | ✅ | ✅ | ✅ | 指出索引3超出范围，提供修改索引、负索引和安全检查 |
| 7 | AttributeError（字符串调用 append） | ✅ | ✅ | ✅ | 解释字符串无 append，提供拼接与改用列表两套方案 |
| 8 | ModuleNotFoundError（缺少 pandas） | ✅ | ✅ | ✅ | 详细安装步骤，区分虚拟环境和权限问题，验证方法清晰 |
| 9 | ValueError（字符串转 int 失败） | ✅ | ✅ | ✅ | 给出预检查和异常捕获两种稳健处理方式，附带测试用例 |
| 10 | RecursionError（无终止条件递归） | ✅ | ✅ | ✅ | 明确指出缺少 base case，补充 `if n <= 1: return 1`，验证正确 |

**V1 整体评估**：
- **错误分类准确率**：10/10（100%）全部正确定义为语法错误或运行时错误并指出具体类型
- **根因定位准确率**：10/10 均准确指向具体代码行并解释原因
- **解决方案有效性**：10/10 提供的修复代码直接可用，多数给出多种备选方案
- **推理步骤完整性**：10/10 严格遵循“第1步-第2步-第3步”的 CoT 格式输出
- **综合评分**：100% 完全满足 Prompt 设计要求

**V1 优点**：
- 三步推理框架清晰，角色设定有效（“资深 Python 后端调试专家”）
- 对常见错误的根因分析深刻，不浮于表面
- 解决方案兼具教学性（解释为什么出错）和工程实用性（多种方案供选）
- 自动附带了验证方法，便于使用者确认修复效果

**潜在的优化方向（V2 可选改进）**：
- 可要求输出“错误预防建议”，引导良好编程习惯
- 可加入“同类错误常见变体”提醒（如 KeyError 的同类是 AttributeError 错用）
- 当前已可直接用于自动化 Bug 排查助手，无需必须修改
